# 🚀 Tabitomo: 한국 AI 여행 플랫폼
💡 tabitomo는 인공지능 기술을 활용하여 사용자에게 최적화된 한국 여행 일정과 맞춤형 추천을 제공하는 혁신적인 플랫폼입니다. 기존의 정형화된 여행 정보가 아닌, 사용자의 선호도와 상황에 기반한 개인화된 여행 친구가 되어 드립니다.

기간 : 2025.8.12 ~ 2025.10.1
인원 : 5명

🌟 주요 기능 (Features)

AI 기반 맞춤 일정 추천: 사용자의 관심사, 예산, 동행자 등을 분석하여 최적의 동선과 테마를 갖춘 여행 일정을 자동으로 생성합니다.

여행 스토리북 제공 : 여행 중의 경험을 손쉽게 기록하고 공유할 수 있는 스토리북 기능을 제공합니다.

챗봇 : 여행 전 모르는 정보를 물어보거나 사이트의 Q&A등 다양한 정보를 자동으로 제공합니다. 

🛠️ 기술 스택 (Tech Stack)
프로젝트에 사용된 핵심 기술 스택을 Shields.io 뱃지를 사용하여 시각적으로 표현했습니다.
